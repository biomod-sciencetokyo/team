初期設定（管理者用・最初の1回だけ）

  1. GitHubの Settings → Developer settings → Fine-grained tokens で、このリポジトリだけに Contents: Read and write 権限のトークンを作成します。
  2. 下のフォームにリポジトリ情報・トークン・チームで共有する「合言葉」を入力して保存します。 トークンは合言葉で暗号化され、admin-config.json として保存されます（トークンそのものは公開されません）。
  3. 以降、メンバーは合言葉だけでログインできます。
